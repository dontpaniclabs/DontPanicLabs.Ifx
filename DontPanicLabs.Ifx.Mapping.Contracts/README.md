# DontPanicLabs.Ifx.Mapping.Contracts

Base mapping contracts for the Don't Panic Labs Ifx framework.

Provides `IMapper` — a technology-agnostic abstraction over object-to-object mapping. Depend on this package in your application code; depend on an implementation package (e.g. `DontPanicLabs.Ifx.Mapping.DtoMapper`) in your composition root.
